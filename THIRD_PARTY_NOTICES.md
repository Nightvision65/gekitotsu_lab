# Third-party components

gekitotsu_lab is derived from gekitotsu_java and gekitotsu_rust. Project code uses the root MIT LICENSE; the Rust core's original MIT notice is preserved in rust/vendor/LICENSE. Provenance and local core corrections are recorded in rust/vendor/PROVENANCE.json.

- Gekitotsu Java: https://github.com/xx786029704-arch/gekitotsu_java
- Gekitotsu Rust: https://github.com/xx786029704-arch/gekitotsu_rust
- FlatLaf 3.5.4: Apache License 2.0. Its bundled license is retained in the application JAR.
- Jackson 2.18.3: Apache License 2.0. License and NOTICE files are retained in the application JAR.
- The Windows runtime is generated by jpackage from the selected JDK. Its vendor license and third-party notices are included under runtime/legal; they are separate from this project's MIT license.
- The inherited JNI binary has no public JNI build project in this repository. Its legacy rules and binary identity are distinct from the source-built observers; see docs/ai/unit-hp-rules.md.
- Current distributed JNI and reference JAR identities, versions and rules are recorded in app/kit-manifest.json. The binary contains diagnostic source-path redactions; source and license notices are retained. Its rules differ from catalog-hp-v1.

Game names and game assets belong to their original authors. This is an unofficial fan project. The project MIT license does not replace third-party licenses or grant ownership of game assets.
