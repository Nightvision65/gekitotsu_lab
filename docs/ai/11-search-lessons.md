# 通用搜索经验与证据边界

本页保存有条件的搜索方法，机制查[基础机制](08-formation-fundamentals.md)，评分/选拔查[阵集政策](10-benchmark-usage.md)，每批执行与记录查[持续研究](formation-tuning.md#22-搜索中持续研究候选再决定下一步)。具体slot、参数、成绩和用户选择留本地实验记录与实验，不能推广为游戏定律。

## 约束、参照与真实父阵

| 条件 | 含义与用法 |
|---|---|
| 用户硬约束 | 明确不许改的字段、数量、预算或配对；生成拒绝、评测/交付再验 |
| 阶段搜索选择 | 为隔离因素暂时固定的参数；扩大时另冻规则与run，不篡改旧输入 |
| 机制假设 | 相位、恢复、支撑等候选理由；不是最高胜率的证明或强制布局 |

角度与位移上限写清参考阵、方向及跨0°圆周差，不能逐代换参照累计越权。新任务识别自己的槽位与职责，不用历史默认的固定x、双剃间距或弓角。扩圈前回读候选与计划，算“真实父阵值+offset”的绝对范围；榜首在内部就不能误称边界未扩，模块名也不能代替实际写入字段。

位移额度另写分组和度量：每组独立上限与全阵位移合计是不同约束，逐轴界限与欧氏距离也不同。同一支撑组多实体同步移动时，是否合计须服从用户定义，不能自行重复扣额度；独立组可在各自界限内联合。完整操作见[已选基底微调](formation-tuning.md#23-已选基底的小范围微调)。

每份计划只引用当时已完整、核验且实际用于决策的数据。后完成的验证/遥测用于后续选择与解释，不倒写成早期依据。真实父阵、原阵与当前推荐三种比较分别标注，父阵不同不能将全部分差归因于本次字段。

## 分离对照、联合收益与计分饱和

先分别测位置、角度、成组位移、高度、顺序，再查有效参数的联合；保留不变父阵、温和改动和持平点。单字段失败不排除联合收益，两个单项有效也可能相互抵消。跨模块保存合法F/A/B/AB四角，收益不能直接相加。

条件交互为`S(A,B)-S(A,B0)-S(A0,B)+S(A0,B0)`，衡量该池非加性，不证明物理机制。逐对手`s∈{0,0.5,1}`时先算：

```text
prediction_i = min(1, max(0, sA_i+sB_i-sF_i))
residual_i = sAB_i-prediction_i
```

共享翻盘和上下界会造成饱和，截断残差仍是条件非加性，不能全叫负干扰。保存正/负残差，按明确问题补反事实与少量重放。两个单项都退步仍可能联合提升，不能仅凭单项负收益剪去全部联合方向。

删除辅助再换火力是耦合改动，先补合法“只删除”对照，再研究删除背景下的替换收益。结构替换重新核算每个模板的实际预算、初始加速、顺序和布局；等初始等级红蓝替换还改变耐久、支撑与后续加速度，一套布局差不能否定整类组合。墙体、防护、治疗和火力都可成为因子，不能只扫输出玉。

## 几何、时序、支撑与战术职责

x同时改变位置与初始计数，核心移动耦合默认seed。整模位移只保持初始cnt，仍改几何、支撑、覆盖和存活；不能用结果分差或单个时序公式确认因果。y小改可能落在同一平台，也可能跨边缘；生成器固定有向dx/dy只证明初始关系，不保证全战高度/间距。

支撑联动还可能改变辅助职责：[的玉](knowledge/units/42-的玉.md)移动会改变读取目标坐标的敌方追踪，[愈玉](knowledge/units/18-愈玉.md)移动会改变治疗脉冲覆盖。完整列出联动实体和字段，不能将整组收益全部归于主火力高度或墙承伤；几何稳定也不证明这些职责不变。无合法独立反事实时保留耦合解释。

突击组连同支撑、单位顺序和延后/再触发窗口分析；几何、单枚位置、高度与角度先分离再联合，保留非最速方案。车体碰撞数、在场弹幕或累计受伤不能单独证明某枚玉的段数、出手或机制。多壁防护区分撞前首次覆盖、共同受击后首次恢复和后续循环；实际弹幕还要检查重置、存活、展开与几何，不以单壁最速或回复量替代整组保护。机制控制阵不计强度候选，必须记录ID/帧上限与证据身份。

时序特征、有效命中和胜率是不同层，计算见[弹幕时序](13-volley-timing.md)。均匀化失败或非最速胜出只限定已测背景，不升级为普遍规律。防守位置、墙承伤/支撑分离与去支撑控制查[独立防守专题](knowledge/defensive-positioning.md)。

## 迁移来源、角度集合与职责分配

借鉴先匹配整体战术、加速、核心、兵种数量、绝对/核心相对位置和保护，再借角度/间距；来源高分不代表本阵收益。先固定目标父阵，只换模块做完整对照，再搜邻域；一次拼接失败只否定已测组合，不否定整类战术。具体来源记录和分离设计见[搜索设计](04-search-workflow.md#从已有强阵提取参考)。

多枚同类防御单位要分开考察角度集合与位置职责分配。只允许改角度时，固定坐标、类型和顺序，三枚同一集合最多6种不同角度分配；相同角度导致重复按纯码去重，不能实际换slot。

角度跨度可作经验剪枝：排序后计算圆周间隙，最小覆盖弧为`360°-最大间隙`，全相同为0°。分别统计全来源、高分来源和结构匹配来源，纯码数与不同角度集合数也分开；近似阵族和重复配置频次不是独立证据。跨度不是评分目标，经验范围不变成合法性限制，留外围对照与实测例外。

## 平台、边界与收敛范围

单点爬坡会漏掉持平平台、其他结构背景和条件联合。有力点在边界时向该方向扩圈、补邻近组合；范围仍服从用户允许字段。受约束后没有可行新点时，保存零新增检查，不重复模拟凑扩圈。单轮无提升、对局多或连续若干轮无收益都不证明全局收敛。

预算允许时对推荐点查小邻域、有效参数扩圈、联合和持平平台。若新点胜出，说明是否还查过新点下一圈；父阵验收不是新点穷尽。无提升只说明受测空间未发现更高分，不证明多字段、换兵、顺序、其他种子或全阵码最优。

中途2000可改变验证入围域：验证峰靠近已验证区域边缘时，从已有完整200且有竞争力的相邻区域另冻小批，不继续只按训练榜首取同簇。区分训练域已覆盖与验证域未覆盖；未测邻点不补成失败/平局。保留旧名单、当时证据和新规则，名额按唯一纯码累计。

## 从对手变化学习，而不只追总分

对真实父阵和有信息竞争者计算逐对手增/失/净分与完整索引。持平可能是翻盘与失守抵消；略低分也可能有独特对手收益。按兵种/组合、加速、核心位置/类型、攻防结构看分群N与前后成绩，组可重叠，不相加或事后改权。

选型前分开主目标、子群门槛与同分次序；子群优先的排序可能选中总体较低的版本，必须写出实际取舍。子群纯胜数增加时，D/U转胜与原胜转负也可能使该群半分得分下降，两种指标分别列出。总体细差换来子群收益时报告净分与百分点；互不支配的版本并列，存在覆盖者的备选说明其额外保留理由。

跨池同名“高速”“带缮”群的成员和N不同，按纯码拆交集/新增域，再比同对手变化。验证子群改善不能替代完整大集同名群；总池、交集与差集分别报告。强度排名截取的验证池也不是均匀随机总体。

先写关键机制预测，再从改善与退步各选少量共同对手详细核验；无某类变化如实写无。保留反例和不确定性，不能用未验证解释直接密集扩搜。小批定向样本不是随机样本，不能代替完整池强度证据。相关性、源码机制、真实事件与因果解释分层保存。

## 将Kit分析纳入选方向，而不只看总胜率

关联已有完整结果与元数据，优先离线聚合核心位置、兵种、加速和核心类型画像，再按问题补遥测或贡献分析；调用接口前确认会否新增模拟。分析发现要导出下一批对照，STATE/LEARNING区分“已运行”“实际用于决策”“未覆盖”，JSON已保存不等于充分研究。

贡献低的线索可导出调位、改角度、换兵、减少重复或重分军资的假设；注意delta方向和删除联动，不当作普遍单位价值。热图三种空间含义、U口径、共同窗口、受创/回复寿命混杂、来源链和空查询统一见[分析使用](knowledge/analysis-usage.md)，不在各流程复制字段解释。

## 缓存、资源与结论强度

同名不等于同码，同分/同HP/同结束帧也不证明轨迹等价。仅完整同纯码、对手、物理侧位、引擎/适配器、帧上限、seed政策及raw哈希通过后缓存复用。阶段重合可省模拟，不构成新增独立样本；计分局数、跨池唯一身份、实际新增（含重复、控制、诊断）分开记，未知失败工作量不填0。独立父阵快照的核验见[后台与续跑](formation-tuning.md#后台评测与续跑)，不能把单码完整冒称整批完成。

双侧均分只在两侧完整同N后报告，高1P初筛可能漏双侧强者；镜像开局、相同首发和1px几何差都不能单独证明后续胜负因果。物理索引查[数据契约](data-contract.md)，计分公式与精确同分查[评分政策](10-benchmark-usage.md#评分与晋级)。

固定基准净增分是可复现结果，大集细差列净分与百分点，保留次名其他池/侧优势，不称未知对手显著更强。结论交代受测范围、未测空间、原游戏状态和失败预测；未提升保留基线，持平备选按取舍说明。交付与知识分层按[实验契约](05-experiment-contract.md)，具体证据仅在各自本地实验记录中查阅，公开知识不依赖这些文件。
