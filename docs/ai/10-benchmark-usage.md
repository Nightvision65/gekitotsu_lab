# 阵集、评分与阶段选择

本页维护阵池角色、评分和阶段。操作见[评测与逐池核验](formation-tuning.md#评测与逐池核验)，记录见[实验契约](05-experiment-contract.md)。比较须采用同一政策；冻结原始证据不可改写。

| 阵集 | 固定入口 | 适用阶段 |

### 来源与证据独立性

标准200来自固定Rust上游的`fixtures/games/2P.txt`。完整10433的来源、快照、预算审计和映射见[阵池审计](../../benchmarks/external10433/README.md)。现存验证2000与训练200精确重合138阵；完整10433与训练200重合198阵，包含现存验证2000。最终同时报告10433和排除198条训练精确重合后的10235，不生成删减版正式输入。

验证2000取自完整10433对标准200表现排序中的竞争阵，用于持续验证。实际评测始终读已确认的固定文件，不在搜索任务中重新构建排名池；阵池来源与当前候选对局的完整性分别核验。

验证池通过训练表现选出，三池均为可见研究基准；纯码去重不保证阵族独立。因此不称独立未见测试集，不用其成绩宣称未知对手上的泛化胜率。

## 评分与晋级

对话、文档、表头和报告统一称“胜率”，平局按半胜计算，不再另列“得分率”。政策为`timeout-as-draw-v1`：胜1、平局D或帧上限未决U各0.5、负0；胜率为所得胜场除以固定总局数，百分比计算如下：

```text
scorePercent = 100 * (W + 0.5 * (D + U)) / N
h = 2*W + D + U
scorePercent = 50*h/N
```

`scorePercent`、`scorePct`等技术字段对外显示为“胜率”，总体、分群、门槛和排序均用该口径。若诊断需展示`W/N`，称“胜局占比”，不替代胜率或参与默认选拔；复用结果核对实际公式，不能只看字段名。

N始终是完整池的固定局数。保留原始W/L/D/U/E，可另列`D_scored=D+U`。U允许排名和晋级，不能排除拖时间的耐久阵。E、缺局、进程超时或程序失败均不是对局平局；要求完整且E=0、输入/引擎/证据哈希一致才具备比较资格。

默认候选1P、对手2P，65536帧、冻结JAR内Rust默认种子；2P为辅助，除非任务明确双侧目标。双侧同N时分别完成，再以`25*(h1+h2)/N`取算术平均；排名先比较整数半分，再按提前冻结的破同分规则。均分提升不代表两侧均提升。物理侧位和reverse索引查[数据契约](data-contract.md#身份坐标与输入)。

不同阵池、侧位分别报告，不事后发明混合权重。核验通过只证明证据完整，是否更强还须对照基线与取舍。标准200净1分是0.5个百分点、净0.5分是0.25个百分点；大集小分差同样列净分与百分点，不称未知对手上的显著提升。

## 开搜前的原阵研究

先完成或核验复用[原阵三池研究](formation-tuning.md#11-开搜前先充分研究原阵)，BASELINE齐备后开搜。来源原码的只读诊断与稳定态新候选分别记账；新表示按[重力流程](gravity-audit.md)去重验收、重新评测，不继承成绩。

## 训练、竞争验证与决赛

以下200→2000→10433用于常规造阵；已选基底的小范围微调按本节末的2000→10433执行。

1. **完整200迭代。** 前期理解机制并做有对照小批，有实测提升后再加联合与密集搜索。每个进入常规搜索评测的新候选完整200并核验；研究本批后冻结依赖反馈的下一方向，无需逐阵等待2000。小集只作诊断，不代替完整200。
2. **竞争候选完整2000。** 小批取得成果即可冻结高分、温和改动和不同区域竞争者中途验证；反馈用于后续父阵、搜索方向和验证邻域。扩大名单前冻结依据，保存当时可用证据。未入围写“200筛选淘汰，2000未测”，不能写“验证失败”。
3. **综合两池冻结决赛名单。** 优先保留非支配版本，即没有另一阵在200、2000都不差且至少一项更高；同时考虑两池冠军、接近冠军、不同区域和独特对手收益。Pareto是选拔线索，不保证大集胜出。名单与理由须在查看新增10433结果前冻结，不因旧版本已测大集偏向它。
4. **完整10433决胜。** 当前完整造阵流程以10433作入围后的决胜依据，在计划中明确记录；补齐冻结名单的完整大集并逐池核验，保留原阵对照，并列报告200/2000/10433/10235及优势和退步。标准200仍是训练与默认主要强度指标，不用大集胜出掩盖200退步，也不事后混权。用户另行限定为200搜索或2000验证的阶段任务按其范围交付，不自动扩成决赛。

**已选基底的小范围微调默认从完整2000开始，以完整10433结束。** 每个进入微调评测的合法新码直接完成2000并逐池verify，不先用200筛选，也不要求每个新码另补完整200；研究真实父阵与原基底的逐对手变化、分群和代表对局后再定下一批。综合2000总体、关键群、改动幅度和独特收益冻结决赛名单，全部入围版补齐完整10433并核验；“10000”始终指全部10433条。原基底同配置三池研究可核验复用，只补缺项，不能继承其成绩给新码。新码200仅在用户要求或明确诊断需要时补测，未测如实标注；微调默认迭代指标为2000，最终决胜用10433，不混合权重。

操作见[微调流程](formation-tuning.md#23-已选基底的小范围微调)。分别记录“迭代只测某池”与“仅交付该阶段”：限制迭代池不自动取消最终决赛，明确限定阶段的任务仍按其范围完成。决赛名单和新增池另建冻结输出；已完成阶段的证据与当时结论保持原样。

## 规模、预算与完成范围

一轮参考规模为大约4000个唯一阵完整200、大约200个竞争阵完整2000、大约40个阵完整10433，可按空间、竞争和算力调整，不是硬配额或必须凑满的数量。按批去重累计，声明原阵是否计入；候选记录数、唯一纯码数、各池完整阵数、计分局数、跨池唯一身份及实际新增模拟分别记账，包含重复、控制和诊断。

每份run只核验其冻结名单与必测池。增加候选或阵池另建输出，不改旧manifest；200阶段完整不代表双池或三池完成。曾用于选型的数据状态、未测部分和决胜依据写入STATE，历史或主动停止的任务不自动恢复。
