# 可复制任务模板

模板只填写任务特有的目标和边界，执行规则引用[总体入口](README.md)、[研究流程](formation-tuning.md)、[阵集政策](10-benchmark-usage.md)与[实验契约](05-experiment-contract.md)，不在每段重复整套流程。替换占位符才使用，既有STATE与用户选择优先。

## 默认下一轮或改进现有阵

```text
从<用户原阵路径或STATE明确父阵>继续造阵，规则<路径/预算/核心/禁限>，本轮总模拟预算<局数>，侧位目标<约定>。
按AGENTS与docs/ai/README.md导航阅读；完成或核验复用原阵三池与BASELINE研究后，按formation-tuning执行有对照小批。
本轮重点问题：<原阵观察、要改善的对手群、允许改动slot/字段、失败判据>。
用当前生成器、规则/重力门禁和逐池verify；每批研究真实父阵的逐对手收益/损失、核验关键解释后再定依赖反馈的下一计划，中途竞争验证按10执行。
交付精确阵码、各池实际完整成绩与取舍、证据和当前STATE；完整实验按05在本地归档结果，仅提交可公开的通用知识或工具变更，未提升保留基线。
```

## 针对指定阵构造克制阵

```text
针对<目标阵路径>构造克制阵，可用起始阵<路径或从零>，规则<预算/核心/禁限>，侧位<1P/2P/双侧>，预算<局数>。
按现行研究流程理解目标威胁，设计结构不同的合法候选，以接触、核心受创、关键存活和实际来源链核验克制解释。
指定目标表现与标准200等通用池结果分开报告；辅助反侧与精准碰撞原游戏待验状态单列，不以单场胜利声称最强。
```

## 精调现有结构

```text
精调<原阵路径>，保持<组成/数量/顺序/核心等约束>，只允许<slot/字段/范围>，角度/位移参考阵<路径>，预算<局数>。
依现行研究流程先核验原阵前置与规则，未改槽位保留原块；横移、核心移动、支撑与顺序的混杂分别记录。
默认每批直接完整2000并核验后研究具体改善/退步与必要详细对照，再选邻域和联合；不先跑200筛选。冻结决赛名单后补完整10433收尾（“10000”指全部10433），除非用户明确只交付某一阶段。不凭最速、均匀度或总分持平断言等价。
```

## 诊断而暂不改阵

```text
分析<原阵路径>在<冻结评测池>的弱点，先不替换原阵。侧位<约定>，总预算<局数>。
核验已有证据并重聚合分群/热图；按具体问题选择代表对局、必要贡献或详细诊断，避免默认全量重测。
交付三项优先假设，包含具体职责/slot/参数轴、收益群、代价、失败判据与证据边界，保存STATE与诊断结果。
```

## 从已有实验续跑

```text
继续experiments/<run-id>/STATE.md，保留用户当前选择与规则，剩余预算<局数>。
先核验冻结身份和已完成证据，缺原阵前置只补缺项；相同输入不重跑，不覆盖旧结果，不改旧manifest。
本次授权续跑范围<待办阶段>；结束时更新STATE、推荐依据、未测项和下一步。已停止的其他任务不恢复。
```

## 显式seed压力测试

```text
在明确冻结的<gkt-core/观察器版本与HP规则>上，对<入围阵>与<基线>测试seed列表<整数>，对手池<路径>、侧位<约定>、帧上限<帧数>，预算<局数>。
JNI不提供显式seed，不虚构选项；允许时使用现有原生接口或隔离调用程序，不修改战斗核心。
保存逐局结果、双方HP、RNG与构建来源，并与默认seed评测分别报告，不声称代表原游戏随机分布。
```
