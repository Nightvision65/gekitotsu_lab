# 变玉（ID 23）

按RNG生成不同生物，以移动接触、承伤和衍生火力改变战场。

## 身份与适用范围

| 项目 | 固定值 |
|---|---|
| 编码ID / Rust类型 | 23 / `BallKind::Hen` |
| 军资（工作台目录） | 100 |
| 战斗构造HP | 10 |
| 初始化speed | 100 |

依据Rust提交`149e365221b09330a72d9a6a1804605e3ce4e1f5`与当前`catalog-hp-v1`规则，版本选择见[规则版本](../../unit-hp-rules.md)。本文机制是源码结论；用途与微调建议是基于机制的待测方向，不代表单独胜率证明。军资/中文名来自工作台目录，HP与时序以Rust构造和分支为准。先读[共通规则](common.md)中的兵玉部分；[文档清单](coverage.json)保存单位条目与源码身份。

## 触发与节拍

初始化模100；cnt=108生成并归零。

speed>0时，普通工作台x的初始cnt为`-((x+16)%speed)`；这里的计时是有效递增次数，跳跃会暂停递增，受伤等可能改变状态。speed=0不套取模公式。

## 详细机制与生成对象

- 沿r偏移25生成；spawn_type=round(RNG×7)，2/3映射Drill，4为Solid，5为Shock，其余Weak。不能当四种等概率。
- Drill：HP7，沿初始方向加速至25，team接触扣1并产生Atk、速度重置-5。Solid：HP20，初速2，接触扣1并产生Atk和小幅后退，触地反弹。
- Shock：HP10，初速2并附加旋转位移；每60次自身更新向core_x/core_y目标发速度10的Gun弹；接触扣1、产生Atk并后退。Weak：HP3，速度约3并平滑朝目标转向，接触产生Atk、扣HP并产生衰减退速。
- 这些生物登记unit而非Ball，没有普通兵玉的heal、dead_last与复活处理；按各自越界、触地及HP分支结束。其接触攻击和子弹须追踪到生成来源。

## 受击、恢复与死亡

没有额外的受击重置分支；本体仍按共通规则扣血、治疗和死亡。

本体受击、支撑、跳跃、heal与死亡顺序见[共通规则](common.md)。独立生成物不自动随本体死亡消失；依附物是否清理由各自分支决定。

## 改阵与对手诊断

固定seed政策和输入，检查实际生成类型及生存轨迹；核心移动会改变默认RNG，不能把全部收益归因于几何。r决定出生点和初始路线，各类型效果分别观察。

发现对方带此单位时，同样检查它的支撑、保护、实际出手位置与生成对象；先选少量目标对局确认机制是否生效，再用完整评测判断改阵收益。
