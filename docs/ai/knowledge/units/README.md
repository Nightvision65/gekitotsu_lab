# 单位百科

改阵前按实际解码ID查阅本阵每类单位，包括核心、墙、加速器和辅助；对对方感兴趣的单位同样从这里查。先读[共通规则](common.md)，再读所需单位页，同任务同规则版本可引用已记录的阅读；新增单位或职责变化时补读。不再要求每次改阵前逐一阅读全部单位源码；百科缺项、版本变化、机制矛盾或具体疑问才按页尾源码定位补查。

当前提供45种非核心类型与两类核心的机制条目。[文档清单](coverage.json)记录条目、源码身份与规则；生成物随来源单位说明。

## 版本与阅读方法

机制基础与当前后端HP见[规则说明](../../unit-hp-rules.md)。源码catalog-hp-v1使用蓝加速器100、电梯壁75；内置JNI使用150/35。按后端与哈希选择规则，不混用成绩。

每页依次说明身份/成本/战斗HP、初始化与实际触发、生成物、受击恢复死亡、x/y/r影响与源码符号。用途和参数方向是机制支持的假设，强度仍由完整评测决定；对象计数不自动等于全局帧，发射均匀不自动等于命中连续。

## 常见问题入口

- 首次开壁与受伤恢复、54+60n、43/55及53/55双壁：[壁玉](19-壁玉.md)。
- 双炮相位差60与压壁的必要条件：[炮玉](09-炮玉.md)；弩等间隔火力：[弩玉](07-弩玉.md)；通用计算：[弹幕时序](../../13-volley-timing.md)。
- 护壁、结界、实体盾与近战拦弹的差别：[壁玉](19-壁玉.md)、[界玉](24-界玉.md)、[盾玉](04-盾玉.md)、[剃玉](10-剃玉.md)。
- 核心/墙修理与兵玉治疗：[缮玉](17-缮玉.md)、[愈玉](18-愈玉.md)；碰撞保护与重建：[贽玉](41-贽玉.md)、[圣玉](34-圣玉.md)。
- 突击落点和动态高度：[近突击壁](55-近突击壁.md)、[远突击壁](56-远突击壁.md)、[采玉](47-采玉.md)、[箱玉](44-箱玉.md)、[电梯壁](60-电梯壁.md)。
- 追踪改向、拦截后残余爆炸：[的玉](42-的玉.md)、[导玉](16-导玉.md)、[迎玉](40-迎玉.md)、[查玉](54-查玉.md)、[核玉](49-核玉.md)。

同一问题涉及双方时，两侧对应单位都查阅。单位专属机制在各页维护；基础机制与时序专题保留跨单位方法，具体阵的最佳坐标、分数和用户选择保存在各自本地实验记录。
