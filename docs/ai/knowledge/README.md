# 造阵知识库

这里按问题查机制与研究方法；执行步骤见[研究流程](../formation-tuning.md)，完整文档导航见[AI文档入口](../README.md)。知识正文保存现行结论、适用版本和证据边界，具体实验过程留原实验。

## 理解阵型怎样运转

[单位百科](units/README.md)按实际解码ID解释构造、行为、受击/回复/死亡与生成物，覆盖标准200的45类非核心和两种核心；改阵前读共享机制、本阵全部类型，也可查对方单位。[造阵基础机制](../08-formation-fundamentals.md)解释跨单位的坐标、重力/支撑、计时、更新顺序和配合约束。[弹幕时序](../13-volley-timing.md)帮助计算首发/持续节拍并核验实际命中衔接。[HP规则版本](../unit-hp-rules.md)用于确认源码、目录和旧DLL的差别。

[战术知识库](tactics/README.md)用于识别狙击、弹幕、突击、消耗防守、圣贽、加速和混合体系，研究获胜路径、辅助衔接与相性变体。[防守部署诊断](defensive-positioning.md)用合法对照区分防区位置、墙体防御与支撑、纸壁破坏后的实际效果。这些独立专题保留各自条件，不用某阵优胜参数代替通用机制。

## 从数据选择下一步

[通用搜索经验](../11-search-lessons.md)用于设计条件/联合对照、识别平台与边界、解释非加性并限定收敛结论。[批量实验知识](batch-design-dedup-defense.md)用于保序去重、别名映射、职责分组和检查迁移模块实际字段。[分析使用](analysis-usage.md)解释画像、核心/槽位热图、删除贡献和来源链的用途以及样本/寿命混杂；具体字段查[数据契约](../data-contract.md)，逐次HP和攻击查询查[详细模式](../detailed-mode.md)。[阵集政策](../10-benchmark-usage.md)解释固定分母、U半分、三池与双侧样本含义。

用户选定版本、局部配合、参数、成绩、反例和停止状态保存在各自本地实验记录，服务继续对应阵型；公开知识不依赖这些文件，也不把具体坐标、角度或历史成绩推广到其他任务。`mechanics/timing/search-lessons/benchmark-policy`保留为旧链接入口，正文分别归上述专题维护。
