# 批量候选：身份、别名与联合改动

本页维护批量实验的数据组织与模块迁移方法。稳定态模型及去重键见[重力审核](../gravity-audit.md)，对照和扩圈见[搜索经验](../11-search-lessons.md)，防区位置与墙体职责见[防守部署](defensive-positioning.md)。

## 冻结前去重，冻结后保留权重

按[阵码契约](../02-formation-format.md)解析名称、纯码和元数据，校验字符、核心、边界与回编码；不靠换行猜多阵、不修剪非法字符，也不重排单位。先按完整纯码保留首次顺序，保存所有源文件/原索引/名称别名→唯一条目映射和前后条数。相同坐标但顺序不同、仅同分均不能合并。

候选再用stable_dedup将全部来源的稳定几何统一去重，保留源阵→几何类→实际代表纯码。跨批范围显式声明，本轮预期由任务程序成批验收。几何合并只用于搜索去重，不证明源原码战斗等价，不能转移成绩；即使x/角度不变，改y仍可能影响落稳前出手、效果触发与敌方首波命中。

纯码去重、稳定态去重、规则验收和对局缓存分别记账。缓存要求实际双方纯码、引擎/适配器、物理侧位、帧上限、seed政策及原始哈希一致。新约束从已有证据筛出有效候选，列有效/不合格/未跑数，不为凑规模重跑。

固定三池只核验身份、条目、顺序与原权重，不回写转换、不因重复或候选表现删对手。自建新池另冻原始集合、规范集合、去重政策、哈希与映射；独立性还要检查阵族和使用状态，不能仅凭纯码不同判断。

## 按实际职责设计联合对照

按配合关系提出分组，如同火线的两炮、循环压制单位、平台和所撑防御玉；分组是待验假设，不自动成为固定配对。保留父阵F、只改A、只改B、同时A+B，必要时在不同背景重复小网格。反事实预算与稳定预期同样合法；组合收益不简单分摊到组成变化。

角度、位置、初始化相位和实际节拍分别记录：x同时影响几何与计数，初始y不保证稳定高度，等x差不等于循环间隔。墙体变化可能同时改变承托、遮挡和敌方突击落脚；无合法分离对照只能归于完整方案，不称纯高度收益。分群在看收益前定义，报告N、净分和总体取舍，重叠组不相加。

## 迁移前列出实际写入字段

由源方案与真实父阵的精确changes列每个模块的slot/字段。以火力命名的模块也可能移动墙、盾或辅助；仅迁移名称中的单位不能继承整组收益。复制未变化字段也可能覆盖另一模块的改动；重叠写入明确优先级，或拆因子保留条件对照。

生成后核对实际改动、稳定支撑与功能，落稳带来的额外变化也记入。名义单因子不代表全战只改变一个机制；具体参数、成绩、失败预测和反事实结果留本轮实验。竞争分支保留高分、温和变化、不同区域和独特收益，名额与允许取舍在读取下一池成绩前冻结，阶段规模按[阵集政策](../10-benchmark-usage.md)。
