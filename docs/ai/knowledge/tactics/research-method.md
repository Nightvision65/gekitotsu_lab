# 研究方法、证据与上下文控制

完整数据保存在磁盘，模型只读取当前问题需要的有界证据。结论、未决问题、规则身份与读取入口必须落盘，不能依靠一段无限增长的对话记忆。

## 从全体到具体问题

| 层次 | 读取内容 | 作用 |
|---|---|---|
| 总览 | 本目录README、实验STATE、REPORT | 确认任务阶段、身份、完整性与边界 |
| 分类 | 11类页、相性、互斥描述分支 | 确认主要优势/弱点和类内差异 |
| 对手画像 | 明确兵种、速度、核心分箱的N与两侧W/L/D/U/E | 检查相性是否集中在某种结构 |
| 案例 | 有问题的胜、败、D/U、临界局和反例摘要 | 提出并检验具体机制解释 |
| 原始事件 | 指定单局、帧窗、侧位、槽位和字段 | 核查出手、命中、恢复、起落及来源链 |
| 新观察 | 仅缺失字段的少量隔离详细对照 | 补空间或状态证据，并验证没有改变战斗 |

从高层发现问题，再下钻到低层；不把大批JSON逐份灌进上下文。每个原始片段应服务一个明确预测，输出可支持、否定或仍不确定，保留失败预测。

## 固定身份与完整性

全量有向矩阵包含换边时，先核对身份和索引，不再重复扩算。分别记详细评测、独立后端对照、前缀与空间诊断的实际局数；相同冻结身份的完整证据先核验复用。

冻结原阵顺序与纯码、引擎二进制哈希、HP规则、种子、帧上限及计分政策。独立读回核验文件SHA256、请求、结果、HP账本和来源求和；跨后端逐局对照可观察的胜负、HP与结束帧。新增空间字段还须验证原有事件、双方HP、RNG及其他输出未改变。

原始事件按问题和窗口采集，在本地完成聚合、案例与核验后按任务约定归档或清理。若已清理，摘要不能冒充仍可读取的逐事件证据；需要精查时重新生成少量目标局，不默认重建全矩阵。运行现场和统计附件不提交到公开仓库。

## 分页和字段投影

使用[detail_slice.py](../../../../tools/ai/detail_slice.py)读取重新生成的临时单局，默认20条，最大100条，支持帧、目标侧/槽位、事件种类与sequence游标。`--fields`仅输出所需字段，可用点号下钻；`hasMore`与`nextAfterSequence`用于下一页。脚本只加载指定单局，不枚举全体原件。

```powershell
conda activate opencode
python tools/ai/detail_slice.py path/to/temporary-battle.json.gz --from-frame 768 --to-frame 840 --side 1 --kinds damage --limit 12 --fields sequence frame slot attackerEntityId effectiveHpLoss hpAfter x y
```

示例路径是占位符，替换为自己生成的本地对局文件。下一页保持相同过滤，增加`--after-sequence`上页游标。先判断片段是否回答问题，不为读完文件持续翻页。每次只加载一局JSON到本地进程内存；批量分析应读取自己生成的CSV/JSON聚合附件，不逐局翻页读取整个阵池。

## 按需空间上下文

隔离观察器扩展[源码工具](../../../../tools/ai/tactical_detail_context.py)，仅作用于明确指定的隔离overlay及workspace。默认关闭，不替换原发行包，也不改写已有冻结结果。

新二进制支持可选请求字段：

```json
{
  "spatialContext": {
    "fromFrame": 768,
    "toFrame": 840,
    "attackerSide": 0,
    "attackerSlots": [1, 3],
    "victimSide": 1
  }
}
```

这只是完整请求中的扩展示例；p1/p2、mode等仍须提供。fromFrame/toFrame必填，side为0=1P、1=2P，slot0核心；可另选victimSlots。各过滤条件取交集，生成单位slot=null不匹配指定初始槽位。非法区间、侧位、空槽位列表在模拟前拒绝。

选中HP写点才附加`detail.battleContext`：受击者精确坐标、攻击者/生成根、来源对象、两车位置与运动、真实核心和瞄准目标，以及可读到的跳跃、onSide、角度和计数。`contextEventsStored`统计实际存储条数。默认不增加这些事件字段；仅在请求开启时记录，并核对实际存储条数。

字段是当前HP写点的可读状态，不是把整场所有实体同时暂停得到的几何快照。当前执行元素可能暂时从elements取出，故活体为空须如实保留；不能用aimTarget填充trueCore，也不能把另一帧位置补成当前值。攻击者位置与独立攻击区域位置可以不同，应同时看sourceObject。保留来源链与旧事件，避免新增观测字段改变归因。

在本地保存隔离构建命令、二进制哈希、过滤窗口与逐字段对照，重建也只在隔离目录完成。

## 让换上下文后仍能继续

STATE头部应直接给当前阶段、权威结果、已完成范围与未决问题。具体研究条目保存“观察→预测→证据路径/哈希→结论→边界→下一步”，精确slot、坐标和成绩放原实验，通用知识只保留有条件机制及可独立使用的说明，不引用私有实验。

继续同一任务先读STATE及当前问题相关的一页，只有规则或输入不一致才追查原件；已完整核验的数据按身份复用。修改引擎、HP、种子政策或阵码后，不继承旧成绩。完整矩阵不证明全局最优，也不替代候选的合法反事实和完整池评测。
