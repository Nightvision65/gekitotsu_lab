# 相性与类内变体

类名用于查找思路。研究相性时，先找相似结构和相同失败链，再比较父阵与候选；同类可以具有不同核心位置、推进速度、防区和恢复链。

## 建立可解释的矩阵

先冻结阵池、侧位、后端、帧上限与seed，逐侧报告固定N和W/L/D/U/E，按[阵集政策](../../10-benchmark-usage.md)评分。若汇总双方角色，完整交叉矩阵的N=2×本类阵数×对手类阵数；互补结果不是独立发现，同集合双侧对角50%也不证明每阵均衡。

相性表应由使用者针对当前构建生成。类别均值反映阵池权重，不能直接当作组件因果收益，也不能把A胜B、B胜C推成A胜C。

## 按失败链提出问题

| 对照对象 | 需要检验的问题 |
|---|---|
| 加速与耐久防守 | 接敌窗口、碰撞净交换能否压过恢复；保护链是否持续工作 |
| 瞄准与多层防区 | 真正挡点、诱导目标与真实核心之间有什么路径 |
| 广域火力与圣贽 | 是否触及圣、贽、复活出口或防护本体；配套火力承担了什么 |
| 突击与留守 | 出击落点是否产生有效攻击；己核因此失去什么保护 |

保留不符合预测的对局，分别检查攻击尚未形成、形成却未穿透、伤核后仍被恢复或碰撞逆转等不同情况。

## 描述变体并建立对照

可拆成可组合的轴：弹幕集中/扩散、核先的数量与维持、推进速度与核心高度、圣贽的保护和出口、突击的近/远/采/箱/界、特殊生成链。互斥类别与重叠组件画像分开统计，重叠分群的局数和收益不相加。

位置分箱必须声明数值边界，不能反向改写历史名称。每格样本量、兵种与速度可能不同，不能把高分直接归因为挪核心。

比较同父阵的小改动及合法联合对照，记录逐对手改善、退步和净计分；按共同时间窗核验事件顺序。候选选拔与微调范围遵循当前[研究流程](../../formation-tuning.md)，不同后端及阵池分开报告。
