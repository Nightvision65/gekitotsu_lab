# 地铁、后击与后突击

这类战术利用对方防区的空间薄弱处。名字只提供线索，成立条件要看攻击者到达哪里、形成什么攻击、实际打中谁，以及己核付出的代价。

## 地铁的阶段链

“借撞击抬车，把兵玉送到车底向上攻击”是一条可检验的空间路线。需要分别核对碰撞抬升、突击起跳、地面停留、再跳与实际命中，不能预先认定全程静止清场。

1. 记录两车碰撞、相对高度与车底窗口。
2. 检查远突发令与接令、起落坐标、落地表面和攻击方向。
3. 分离地面阶段与后续采配再跳阶段的有效伤害，追踪目标及真实核心。
4. 在共同时间窗内比较敌方治疗、支撑与己方失血，检查这条路线能否转化成终结。

地面、飞行、enemy_platform是观察器状态标签，需与实际坐标和更新阶段一起读。车底中央空隙与实体轮廓会影响路线，不能只用单位y与baseY比较来判定穿模或覆盖。

## 后击的位置与火线

后击要求攻击者到达敌后，并从那里实际攻击薄弱区。晚出发可能有帮助，但出发较晚、落在敌车和形成反向有效火线是三个不同条件。

记录落点相对真实核心的位置、朝向、首个挡点、攻击者存活及真核伤害来源；送过去并不保证打穿。双侧须实测，不能复制一侧的坐标与事件解释。

## 后突击的标签边界

“后突击”没有在本项目中规定唯一机制含义。研究时分别记录出发时点、前后相对位置、落地表面、朝向与真实核心来源，再判断实际是晚出发、敌后攻击或其他路线。

## 设计改进对照

控制碰撞抬升窗口、远突相位、地面停留和采配再跳，写清预测改善哪个阶段、影响哪些目标，同时检查跳跃暂停与己核留守的代价。逐对手比较父阵与候选，保留失败反例，不能用单次快速拆解推断普遍克制。
