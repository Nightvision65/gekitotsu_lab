# 辅火：思路、攻防与内部变化

把中等加速与有限远程火力组合起来，在推进交换中用火力补足纯加速阵难以处理的目标。它位于持续弹幕与高速碰撞之间，既可能靠火力终结，也可能通过火力破坏防守后让碰撞或近战收尾。

机制以[当前后端规则](../../unit-hp-rules.md)和单位源码为依据；用途与改进方向是待检验假设，强度需针对自己的候选评测。

## 如何形成攻击

前地辅火常用少量炮、弩、导配合剃、枪和采；近/远突与地刺组件改变接触位置。后空/后中版本则更像加速推进的弹幕体系。必须分别看常规攻击、近战及碰撞对敌核的贡献，不能因加速达到4级就把火力降为无关装饰。

## 如何保护攻击链与核心

较大军资投入加速器后，防守要在壁、剃、的玉、回复与支撑之间取舍；加速器本身也能支撑或承伤。前地核心常需要上下分区保护，采配既可能重新接近敌方，也可能延长己方攻击计数暂停。

## 怕什么，以及如何判断实际败因

可能同时承担弹幕密度较低和碰撞保护不足两种代价；圣贽能改变碰撞收益，突击与弹突可越过局部防区。对地核、自闭等布局应分别核验接敌窗口、火线与碰撞交换。





## 后续改阵的可检验方向

先判断当前版本到底缺火力、接敌位置还是碰撞耐久。比较同一对手的核心伤害来源与加速器死亡后运动，检查地刺是否落到预期表面及采配是否中断火力。对火力和加速做预算交换时必须重新算等级、支撑与存活，不能只按兵种数量预测相加收益。

落到具体阵时，先明确“哪个对手的哪条失效链→只改哪些slot/字段→预计改善哪一群→可能损失哪一群”。先写机制预测，再比较父阵与候选的共同对手；若落点、真实挡点、核心来源或时间窗不符合预测，保留反例并修正解释。不同原阵间的高分差、组件频次与单位目录价格不能替代这个对照。
