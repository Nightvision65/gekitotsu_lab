# 搜索设计：观察、假设与对照

本页决定改什么、怎样比较；执行顺序见[研究流程](formation-tuning.md)，评分与选拔见[阵集政策](10-benchmark-usage.md)，记录字段见[实验契约](05-experiment-contract.md)。每次生成前读[基础机制](08-formation-fundamentals.md)、本阵单位、rules和STATE，并完成原阵研究。

## 把任务目标变成可检查条件

从用户原码或STATE明确父阵开始，明确通用强度/指定克制、侧位、预算、核心、禁限、可改slot/字段、角度参照与有向成组差。用户硬约束落实为生成拒绝条件和交付检查；阶段固定项另记，不逐代换参照绕过用户范围。赛制未明可声明普通核心、1500军资、满血、工作台边界的探索假设。

本轮对稳定布局的预期也须在生成前写成可执行条件：关注槽位应在何处、由谁支撑、是否允许落到目标区域，以及要保持的相对关系。明确条件作用于原码、稳定态或支撑破坏后状态，不能用初始坐标检查替代稳定位置验收。成批取得稳定态，将原码位移通过阵与未通过阵的稳定态合并去重后，再自动验收唯一布局；位移未通过但稳定态符合预期的可以保留。具体模型与实现范围见[重力审核](gravity-audit.md)。

冻结对手集合与评分，不以画像、2P或额外池替换主目标。给对手加兵种、组合、加速、核心和结构标签用于诊断，列样本N与重叠；must_pass/hard_cases单列，调过参的难例不是未见留出。新辅助池先查来源、哈希、纯码重合与近似阵族，查看后继续调参就不再未见。

## 从观察提出可证伪假设

| 观察 | 可测试的改动轴 | 副作用与反例检查 |
|---|---|---|
| 输出玉未出手先亡 | 位置、防护、突击落点 | 首击延迟、遮挡、预算与支撑 |
| 火力错开或压制有空档 | x、角度、代码顺序 | 几何、初始计数、实际抵达和存活同时变化 |
| 某类对手失分 | 定位具体来源后调整对应防区 | 兵种存在仅相关，不能当唯一败因 |
| 删单位后得分改善 | 合法“只删除”对照，再重分军资 | 删除连带支撑、治疗、保护与时序 |
| 核心早受伤 | 遮挡、诱导、核心微移 | 默认seed耦合，首伤延后不保证胜利 |
| 回复久战失守 | 平台、恢复节奏、有效破核 | 累计受伤受寿命影响，U已经半分 |

每条计划记录“观察→预期机制→候选轴→预期改善群→副作用/失败判据”。本轮迭代池的完整结果决定强度收益，少量同对手详细对照检验机制解释；总分提高而目标群未改善，不能称弱点已修复。具体分析方法见[分析使用](knowledge/analysis-usage.md)。

## 选择搜索方法

程序按规则枚举或抽样受约束的编辑，模型按批次研究单位表、预算、代表败局、逐对手收益/损失和已试变更，提出可执行计划；胜率由冻结模拟器实测。组成与顺序是离散变量，平台和接触阈值使局部反馈不平滑，不能用文字解释或拟合分数代替对战。少量新结构可由模板或合法随机构造产生，不需要先训练生成模型。

常规任务从指定父阵开始。只有任务授权多起点或方法对照时，才比较多流派起点、分支保留、局部拆除重建与模型建议；保留功能组而非任意拼接码段，探索分支不要求每步涨分，最终交付仍用完整实测择优。项目尚未证明某种搜索算法普遍更优。

方法对照冻结相同起点、规则、评测契约与总预算，将基线、筛选和决赛都计入。比较最佳完整胜率随真实新增局数的变化、耗时、合法率、结构多样性及模型调用成本；多次搜索随机种子衡量搜索稳定性，同一确定性阵对重跑不增加样本。局部搜索、结构重建、模型建议逐项对照后再增加复杂度。

评测成为实际瓶颈、且积累足够独立阵族数据时，可研究候选排序代理；按阵族隔离训练与检验，防止近似阵泄漏，代理只安排真测顺序。训练编辑或构造策略还需跨规则/阵池的长期需求与收益证据，动作采用添加、移动、替换、调序等结构操作，不以生成base61字符本身衡量造阵能力。

## 分离因素后保留联合机会

先比较位置、角度、成组位移、高度与顺序，保留不变父阵、温和变化和持平版本；起步±1/±2仅是可选小范围，不是通用边界。结构变化逐阵重算预算、数量、初始加速和顺序。跨模块保留F/A/B/AB合法四角，不将两个单项冠军机械拼接；范围、边界扩圈与交互解释见[搜索经验](11-search-lessons.md)。

新候选先按完整纯码哈希去重，再按上述稳定态并集统一去重，保留全部来源，单位不排序；相同稳定几何是搜索去重依据，不证明源原码对战等价或允许转移成绩。稳定化额外改变的字段也记录；初始成组关系不等于全战动态关系。模块名不证明实际只写该模块，迁移前列真实字段，详见[批量实验知识](knowledge/batch-design-dedup-defense.md)。

## 从已有强阵提取参考

先匹配整体战术、核心、加速、兵种数量与空间分布，再看目标单位绝对位置、核心相对位置和横坐标初相位，最后借鉴角度、间距与局部配合。不要先用想测试的角度筛“相似来源”。相似度只是可解释启发，位置差异大的角度降为弱参考。

保存来源索引/纯码哈希、实际评测池、槽位、位置与角度，明确绝对迁移或核心相对迁移以及差异；用只改位置、只改角度、联合改变分别对照。来源成绩不能当本阵证据，越界拒绝，优胜参数和具体筛法留本地实验记录。

## 根据真实反馈选择后续范围

每批完整核验后按[持续研究](formation-tuning.md#22-搜索中持续研究候选再决定下一步)比较真实父阵、逐对手收益/损失与分群，核验关键解释，再定下一批。中途2000能改变后续父阵/验证邻域，名单与依据在新结果前冻结，不倒写计划。留多样分支，不假定克制可传递。

有限扰动、显式seed或额外侧位作为辅助，另冻配置；JNI无显式seed参数，不虚构选项。停止依据写实际预算、目标或明确受测范围，无提升保留基线，不凭轮数或局数称全局最优。原游戏复核按版本、侧位、可导入性及精准碰撞案例记录；无法运行就标模拟器结果、原游戏待验。
